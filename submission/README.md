## Final video

The recommended rendered draft is 5 minutes 9.8 seconds at 1920 x 1080, 30 fps, with normalized AAC audio. It explains that the dashboard demonstration analyzes recorded CSI footage in real time, distinguishes the recall-prioritized dashboard threshold (`0.0071`) from the balanced evaluation threshold (`0.0265`), and states that an untouched physical-line production trial was not completed.

The rendered video, editable visual deck, original CSI recordings, and narration files are intentionally stored outside Git as media-authoring artifacts. They should be shared through the hackathon's submission or approved media-hosting workflow.
